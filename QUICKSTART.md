# Quick Start Guide - Distributed Database System

## Option 1: Automated Setup (Recommended)

### Step 1: Install Dependencies
```bash
pip install mysql-connector-python
```

### Step 2: Run Automatic MySQL Setup
```bash
python3 db_setup.py
```

The script will:
- ✅ Auto-detect your MySQL configuration (no password, 'password', or custom)
- ✅ Create database and table
- ✅ Optionally create a dedicated user for security
- ✅ Generate config_db.py with working credentials

### Step 3: Configure Node IPs (if distributed)
Edit `config.py` and set your node IP addresses:
```python
NODES = {
    1: ('192.168.1.10', 5001),
    2: ('192.168.1.11', 5002),
    3: ('192.168.1.12', 5003)
}
```

### Step 4: Start Nodes
On each machine:
```bash
python middleware.py 1  # On machine 1
python middleware.py 2  # On machine 2
python middleware.py 3  # On machine 3
```

### Step 5: Run Client
```bash
python client.py
```

Test queries:
```sql
INSERT INTO usuarios (nome, email) VALUES ('Test', 'test@example.com');
SELECT * FROM usuarios;
```

## Option 2: Manual Setup

### For Root with No Password:
```bash
export MYSQL_USER=root
export MYSQL_PASSWORD=
python middleware.py 1
```

### For Root with Password 'password':
```bash
export MYSQL_USER=root
export MYSQL_PASSWORD=password
python middleware.py 1
```

### For Custom User:
```bash
# First create the database manually
mysql -u root -p
> CREATE DATABASE dist_db;
> USE dist_db;
> CREATE TABLE usuarios (id INT AUTO_INCREMENT PRIMARY KEY, nome VARCHAR(100), email VARCHAR(100));
> CREATE USER 'myuser'@'localhost' IDENTIFIED BY 'mypass';
> GRANT ALL PRIVILEGES ON dist_db.* TO 'myuser'@'localhost';
> FLUSH PRIVILEGES;
> exit;

# Then configure
export MYSQL_USER=myuser
export MYSQL_PASSWORD=mypass
python middleware.py 1
```

## Troubleshooting

### "Access denied for user 'root'@'localhost'"
**Solution:** Run `python3 db_setup.py` - it will auto-detect the correct configuration.

### "Can't connect to MySQL server"
**Check:**
1. MySQL is running: `sudo systemctl status mysql`
2. MySQL socket exists: `ls -la /var/run/mysqld/mysqld.sock`

### Nodes can't communicate
**Check:**
1. IPs are correct in config.py
2. Firewall: `sudo ufw allow 5001:5003/tcp`
3. Ports available: `netstat -tuln | grep 500`

## Configuration Priority

The system checks for database credentials in this order:

1. **config_db.py** (generated by db_setup.py) - HIGHEST PRIORITY
2. **Environment variables** (MYSQL_USER, MYSQL_PASSWORD, etc.)
3. **Default values** (root with no password) - LOWEST PRIORITY

For security, use `db_setup.py` to create a dedicated database user!
