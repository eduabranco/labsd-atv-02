## Migration Guide

### I'm starting fresh:
```bash
python3 db_setup.py
```
Done! It handles everything.

### I already have the database:
```bash
# Option 1: Use automated setup (recommended)
python3 db_setup.py

# Option 2: Use environment variables
export MYSQL_USER=your_user
export MYSQL_PASSWORD=your_password
python middleware.py 1

# Option 3: Nothing! Defaults will work if you had root/password
```

### I want to verify my setup:
```bash
python3 verify_setup.py
```

## Configuration Priority

The system checks in this order:
1. **config_db.py** (generated by db_setup.py) ← Highest priority
2. **Environment variables** (MYSQL_USER, MYSQL_PASSWORD, etc.)
3. **Default values** (root with no password) ← Lowest priority

## Troubleshooting

### "Access denied for user 'root'@'localhost'"
**Fix:** Run `python3 db_setup.py` - it will auto-detect the right credentials

### "config_db.py not found"
**Normal!** Run `python3 db_setup.py` to generate it

### "Can't connect to MySQL server"
**Check:**
1. MySQL is running: `sudo systemctl status mysql`
2. Socket exists: `ls -la /var/run/mysqld/mysqld.sock`
